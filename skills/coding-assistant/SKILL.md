# Coding Assistant Workflow

1. Inspect directory structure with `list_directory` or `search_files`.
2. Read target files with `read_file` before making edits.
3. Apply minimal changes using `patch_file` or `write_file`.
4. Verify behavior using `terminal` or `code_runner`.
